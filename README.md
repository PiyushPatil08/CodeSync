## 🚀 CodeSync

A collaborative, real-time code editor where users can seamlessly code together. It provides a platform for multiple users to enter a room, share a unique room ID, and collaborate on code simultaneously.

---

## 🔮 Features

- 💻 Real-time collaboration on code editing across multiple files
- 📁 Create, open, edit, save, delete, and organize files and folders
- 💾 Download the entire codebase as a ZIP file
- 🚀 Unique room generation with room ID for easy collaboration
- 🌍 Multi-language support for versatile programming
- 🌈 Syntax highlighting with auto language detection
- ⚡ Code execution directly inside the collaborative editor
- 🔄 Instant updates and synchronization for all files and folders
- 📣 Notifications for user join/leave events
- 👥 User presence list with online/offline indicators
- 💬 Real-time group chat
- 🎩 Live tooltips showing who’s currently editing
- 💡 AI-powered code suggestions based on language
- 🔠 Adjustable font size and font family
- 🎨 Multiple themes for a personalized coding experience
- ✏️ Real-time collaborative drawing/sketching
- 🤖 Copilot: AI assistant to generate, insert, copy, or replace code easily
